# neurology_score_project
Ekstensi Chrome untuk pencarian cepat &amp; kalkulator interaktif skor-skor neurologi (NIHSS, GCS, mRS, dll) — 100+ scoring system dari berbagai divisi (Neurovaskular, Neuroinfeksi, Epilepsi, Neuro-ICU, dll). Dilengkapi navigasi keyboard, badge kalkulator interaktif, dan referensi klinis cepat untuk residen &amp; dokter neurologi. By Wylie Neuro.
